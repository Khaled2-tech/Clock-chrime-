# جرس الساعة

تطبيق خفيف لأندرويد 6 فما فوق. يشغّل ملف `Hour Chrime.wav` **مرة واحدة** عند رأس كل ساعة حتى لو الشاشة مغلقة، وحتى بعد إغلاق التطبيق من التطبيقات الأخيرة.

- شريط الصوت أو الكتابة يحدد **نسبة عادية** من مستوى صوت الهاتف الحالي (وليس من أعلى صوت).
- يمكن **استبعاد** ساعات معيّنة مع عرض صباحًا / مساءً.
- لا يرن إذا كان الهاتف على **الوضع الصامت** أو **عدم الإزعاج**.

## متابعة بناء ملف APK

https://github.com/Khaled2-tech/Clock-chrime-/actions

1. افتح الرابط وانتظر حتى تنجح عملية **Build Clock Chime APK**.
2. افتح العملية الناجحة ثم نزّل `ClockChime-debug-APK` (داخلها `app-debug.apk`).
3. ثبّت الملف على الهاتف.
4. افتح التطبيق مرة، اضبط الصوت والأوقات المستبعدة، ثم اضغط **السماح بالعمل في الخلفية**.
